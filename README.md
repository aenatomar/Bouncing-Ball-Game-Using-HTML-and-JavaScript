# Bouncing-Ball-Game-Using-HTML-and-JavaScript
🏀 Bouncing Ball Game

A simple and fun Bouncing Ball Game created using HTML and CSS. This project demonstrates how CSS animations, positioning, and styling can be used to create an interactive-looking game directly in the browser — without JavaScript.

🎮 About the Game

The Bouncing Ball Game features a ball that continuously bounces within a game area using CSS animations.

The project is designed as a beginner-friendly frontend project to practice:

HTML structure
CSS styling
CSS animations
Positioning and layout
Keyframes
Visual effects
Basic game-like UI design
✨ Features
🏀 Animated bouncing ball
🎨 Simple and clean interface
⚡ Pure HTML and CSS
🚫 No JavaScript required
📱 Easy to run in any modern browser
🌈 CSS-based visual effects and animations
🛠️ Technologies Used
HTML5 — Used to create the structure of the game.
CSS3 — Used for styling, animations, positioning, and visual effects.
